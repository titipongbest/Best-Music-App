# Best music

แอปเล่นเพลงสำหรับ Android (Kotlin + Jetpack Compose + Media3/ExoPlayer)

## ความสามารถ
- **เล่นเพลงตามโฟลเดอร์** – สแกนเพลงและวิดีโอทั้งเครื่อง จัดกลุ่มตามโฟลเดอร์ เล่นทั้งหมด / สุ่มเล่น
- **เล่น MV** – แท็บ MV รวมวิดีโอทั้งหมด, หน้าเล่นเพลงแสดงวิดีโอในกรอบปกได้ (สลับ ปก/MV) และดูเต็มจอแนวนอน
- **หน้าเล่นเพลงแบบในภาพตัวอย่าง** – ปกใหญ่มุมโค้ง, สีพื้นหลังและสีตัวอักษรดึงจากภาพปกอัตโนมัติ, แถบเวลาบาง, ปุ่ม ก่อนหน้า/เล่น/ถัดไป ขนาดใหญ่, แถวล่าง อีควอไลเซอร์ · เนื้อเพลง · โหมดเล่นซ้ำ/สุ่ม (กดค้างเพื่อดูคิว)
- **เมนู ⋮** – เพิ่มลงในเพลย์ลิสต์, แบ่งปัน, ความเร็ว, ทำเป็นเสียงริงโทน, ตั้งเวลาปิดเครื่อง, โหมดประหยัดพลังงาน, ซ่อน, ลบ และปุ่มดินสอแก้ไขชื่อเพลง/ศิลปิน
- **เนื้อเพลง** – อ่านไฟล์ `.lrc` ชื่อเดียวกับเพลงในโฟลเดอร์เดียวกัน (ไฮไลต์ตามเวลา แตะบรรทัดเพื่อข้าม) หรือวางเนื้อเพลงเองในแอป
- เล่นเบื้องหลัง พร้อมการแจ้งเตือน/หน้าจอล็อก/ปุ่มหูฟัง, รายการโปรด, ปัดปกซ้าย-ขวาเพื่อเปลี่ยนเพลง, ปัดลงเพื่อปิดหน้าเล่นเพลง

## วิธี build
**Android Studio:** File → Open → เลือกโฟลเดอร์ `BestMusic` → รอ Gradle sync → กด Run ▶

**GitHub (ไม่ต้องลงโปรแกรม):** อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repo → แท็บ Actions จะ build ให้อัตโนมัติ → ดาวน์โหลด APK จาก Artifacts ของรอบที่สำเร็จ

ต้องการ Android 8.0 (API 26) ขึ้นไป

## โครงสร้าง
```
app/src/main/java/com/bestmusic/app/
├── MainActivity.kt        สิทธิ์, การนำทาง, แชร์/ลบ
├── MainViewModel.kt       คลังเพลง + คำสั่งเล่น
├── data/                  สแกน MediaStore, ภาพปก+สี, เนื้อเพลง, ข้อมูลผู้ใช้
├── playback/              MusicService (Media3) + ตัวเชื่อม MediaController
└── ui/                    หน้าหลัก, โฟลเดอร์, หน้าเล่นเพลง, เมนู ⋮, เนื้อเพลง, MV เต็มจอ
```
